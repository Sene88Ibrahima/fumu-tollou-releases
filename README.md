# Fumu Tollou — APK officielles

Ce dépôt public contient uniquement les APK Android signées de Fumu Tollou. Le code source du projet reste privé.

## Application Passenger

Version pilote Android 0.2.0 :

https://github.com/Sene88Ibrahima/fumu-tollou-releases/releases/download/passenger-v0.2.0/fumu-tollou-passenger.apk

Installez l'APK par-dessus la version 0.1. Il n'est pas nécessaire de désinstaller
l'application.

## Application Chauffeur

Version Android 0.4.0 :

https://github.com/Sene88Ibrahima/fumu-tollou-releases/releases/download/driver-v0.4.0/fumu-tollou-driver.apk

Installez la mise à jour par-dessus l'application existante. Ne désinstallez pas l'application : son activation et ses données hors connexion doivent rester sur le téléphone du bus.

Chaque APK est publiée dans une GitHub Release versionnée avec ses notes de
changement. Les tags `passenger-vX.Y.Z` et `driver-vX.Y.Z` restent séparés afin
que les deux applications puissent évoluer indépendamment.
